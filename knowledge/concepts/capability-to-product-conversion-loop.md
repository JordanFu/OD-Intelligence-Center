# 能力—产品转换回路

## 定义

将前沿技术能力持续转化为用户价值的组织闭环：

> 能力发现 → 产品假设 → 有边界的真实发布 → 使用证据 → 模型 / 产品改进 → 资源再配置

它衡量的不是一次模型领先，而是组织能否快速、可靠地学习什么能力值得产品化，以及何时扩大、修改或停止。

## 核心机制

1. **共享结果责任**：研究、产品、工程、设计、安全和运营围绕同一用户任务协作。
2. **问题双向路由**：线上问题可以进入界面、harness、评测、训练或治理策略。
3. **发布梯度**：内部 dogfood、技术预览、广泛可用和高风险使用采用不同门槛。
4. **可逆决策下放**：护栏内快速行动，不可逆事项明确升级。
5. **资源可撤回**：依据证据放大、合并或停止方向，允许新产品冲击既有业务。
6. **监督容量同步增长**：生成能力扩大时，同步投资 review、评测、恢复和上下文。

## OD 对应关系

| OD 维度 | 设计含义 |
|---|---|
| 角色边界 | 研究不止于模型，产品不只是接模型 |
| 决策权 | 以风险与可逆性分层，而非全部逐级审批 |
| manager role | 意图、取舍、对齐、质量和升级责任 |
| 绩效与晋升 | 业务影响、判断、复用、可靠性、跨边界贡献 |
| 工作节奏 | 小步发布、快速反馈、周期性资源再配置 |
| 治理 | 风险分级、可观察部署、例外升级、事故学习 |

## 常见误区

- 把内部 demo 当成可规模化产品。
- 把低阻力理解为无治理。
- 用成熟业务指标过早淘汰探索方向。
- 只放大生成产能，不增加审查和恢复容量。
- 只奖励上线，不奖励及时停止或合并。

## 证据基础

该概念由 Tibo Sottiaux 2025–2026 年多次公开表达、Codex 产品记录、DeepMind 历史材料，与组织双元性及资源配置研究共同支持。综合证据等级 L3；具体企业内部决策权和效果仍需内部数据才能达到 L4。

2026-08-27 的新增公开证据进一步补充两条边界：Meta Project OT 表明资源重配必须允许在技术成熟度、用户价值和人才反馈不足时回撤；MiniMax 的评测底座说明能力转产品之前需要统一评测和发布证据。来源：`../../digest.md` [D01]、[D03]，分别为 L3 窄结构机制和 L2 机制观察。
