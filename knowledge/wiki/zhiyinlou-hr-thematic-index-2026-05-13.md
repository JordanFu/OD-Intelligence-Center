## 高价值资料池

### 1. AI+HR 与智能体

**摘要**：该主题覆盖 AI+HR 战略、智能体应用、DeepSeek 职场落地、技能数据、岗位重构、学习发展、薪酬绩效与员工体验。适合沉淀为“AI 时代 HR 工作重构”专题，把 HR 从流程执行者升级为组织能力、人才供给、效率运营和人机协同的设计者。

**优先精读**：
- `HR Whitepaper / 工作重构：AI+时代 HR 行动指南 HR’s Playbook for the AI Era`
- `HR Whitepaper / HR的新经济学：智能体式AI如何重新定义人力资源效率`
- `HR报告与白皮书 / 2025年HRxAI：价值增长实战`
- `AI+HR 白皮书 / 人工智能改变组织对技能数据思考的五种方式`
- `McKinsey Whitepaper / the-critical-role-of-strategic-workforce-planning-in-the-age-of-ai.pdf`

**提示关注**：岗位说明书可能转向任务拆解、技能图谱、AI 可替代性、人机协作边界和 HR Copilot 场景。

### 2. 薪酬福利、绩效与激励

**摘要**：该主题是“职级体系改革是否经常服务于关键人才激励空间”的核心证据池，集中覆盖美世、怡安、Payscale、Hays、KF 等薪酬调研、薪资预算、福利趋势、薪酬沟通和绩效调薪资料。

**优先精读**：
- `薪酬福利 / 励薪礼才 效启未来：2025-2026美世整体薪酬调研发布会大会材料`
- `薪酬福利 / 【client】2025年美世中国整体薪酬调研发布会-GD All.pdf`
- `薪酬福利 / Transforming merit_ From flawed to fair.pdf`
- `HR报告与白皮书 / cn-reimagining-performance-management-in-the-age-of-ai-report.pdf`
- `HR报告与白皮书 / 人效飞轮：存量时代的高质量增长指南`

**提示关注**：薪酬带宽、市场稀缺系数、年度调薪预算、绩效-薪酬联动、薪酬透明沟通和 AI 辅助定薪。

### 3. 组织发展、人才发展与学习转型

**摘要**：该主题可形成“组织诊断—能力建模—人才盘点—培养项目—继任落位”的知识链路，覆盖组织能力白皮书、平台型组织、技能数据、AI 时代 L&D 转型、领导力项目与继任实践。

**优先精读**：
- `组织和人才发展相关 / 肯耐珂萨《2025年组织能力调研白皮书》.pdf`
- `组织和人才发展相关 / the-state-of-organizations-2026.pdf`
- `智能体 / Building capability engines.pdf`
- `学习与发展 / Keeping pace - leading learning in the age of AI.pdf`
- `推荐书籍 / 领导梯队全面打造领导力驱动型公司.pdf`

**提示关注**：新增岗位/族群前，应先判断是否可通过能力标签、学习路径、项目历练和继任机制解决。

### 4. 领导力与管理者成长

**摘要**：资料横跨领导力峰会课件、组织能力白皮书、麦肯锡高管研究和经典管理书籍，覆盖经营型领导力、技术领导力、人机协同领导力、CEO 核心职责、领导梯队与高管叙事。

**优先精读**：
- `领导力在线峰会课件 / 经营型领导力 - GHR.pdf`
- `领导力在线峰会课件 / 人机协同领导力的5项修炼-GHR青锋.pdf`

**提示关注**：AI 时代 manager 可能从纯管理者转向 player-coach、组织能力教练和人机协同设计者。

### 5. 出海与境外 HR

**摘要**：该主题覆盖海外职场趋势、全球薪酬带宽、激励风险、美国职业/收入回报、印度新劳动法及全球劳动力市场信号，可沉淀为“出海组织搭建—雇佣合规—薪酬福利—人才流动—管理者议题”的知识链路。

**优先精读**：
- `出海和境外HR / 2024年海外职场洞察报告.pdf`
- `出海和境外HR / India New Labor Code.pdf`
- `出海和境外HR / Pave_Guide_To_Comp_Bands.pdf`
- `HR Whitepaper / 2025 SAP HR CONNECT…创业式出海：海外人力资源管理实操分享`
- `HR报告与白皮书 / 全球化智库 2025全球人才流动趋势与发展报告`

**提示关注**：全球雇佣的岗位、薪酬和合规规则不能直接套用国内职级逻辑。

### 6. 劳动法、解除与员工关系

**摘要**：该主题以劳动纠纷司法案例、社会保险纠纷案例和劳动争议新规解读为主，适合建立境内员工关系知识库的法规案例层和操作风险层。

**优先精读**：
- `劳动法 / 20250822劳动争议解释二新规解读：企业合规与破局策略.pdf`
- `解除劳动合同相关 / 中国法院2024年度案例汇编劳动纠纷.pdf`
- `解除劳动合同相关 / 中国法院2023年度案例汇编劳动纠纷(含社会保险纠纷).pdf`
- `解除劳动合同相关` 目录内 4 个文档
- `劳动法` 目录内 3 个文档

**适用边界**：该部分只能做 HR 风险识别和案例学习，不替代法律意见。

### 7. 咨询公司与权威白皮书

**摘要**：McKinsey Whitepaper、HR Whitepaper、HR报告与白皮书构成最大资料池，适合作为全球趋势、CHRO 议题、组织重构、AI 转型、绩效、招聘、员工体验和劳动力规划的权威材料入口。

**优先精读**：
- `McKinsey Whitepaper / the-state-of-organizations-2026.pdf`
- `McKinsey Whitepaper / the-critical-role-of-strategic-workforce-planning-in-the-age-of-ai.pdf`

## 推荐页面结构

1. **知识源地图**：保留完整 234 份 PDF 清单，供追溯。
2. **主题导航页**：本页作为用户进入知识库的首屏。
3. **精读队列**：每个主题 Top 5，按研究价值和紧迫度排序。
4. **Wiki 摘要页**：每次精读一份 PDF，生成一页摘要。
5. **概念页/案例页**：把重复出现的概念沉淀为可复用知识卡。

## 下一步精读建议

优先从三个方向开始：`AI+HR 与智能体`、`薪酬福利与激励`、`组织与人才发展`。这三类最贴近当前“AI 时代职级、岗位族群、职业通道、薪酬激励如何系统化改革”的主课题。
