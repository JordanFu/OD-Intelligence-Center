# AI时代组织与人才机制研究｜内部数据需求包

> 用途：支持“外部公司怎么做 + 我们内部正在发生什么变化”的联合研究，形成可向 CEO / C-level 汇报的组织诊断、趋势判断和行动建议。

## 1. 明天优先要到的最小可行数据包

如果时间有限，先拿这 6 类数据即可启动第一版内部诊断：

1. 当前组织架构和各层级人数
2. 当前职级 / 岗位 / 族群 / 序列表
3. 最近一次绩效分布和高绩效人才分布
4. 最近 2 次晋升数据
5. 当前招聘 JD 和难招岗位清单
6. 内部 AI 使用场景与典型案例

## 2. 建议提供的数据清单

### A. 组织结构数据

- 当前组织架构图
- 各层级人数分布
- 管理层级数量
- 每个管理者 direct reports 数量
- 部门 / 中心 / 小组人数变化
- 近 6-12 个月组织调整记录

### B. 岗位与序列数据

- 当前岗位族群 / 职级 / 序列表
- 各岗位族群人数分布
- 近一年新增、合并、取消的岗位
- 岗位说明书 / JD
- 业务提出的新岗位 / 新序列需求清单

### C. 人才密度与绩效数据

- 绩效分布
- 高绩效员工分布
- 关键人才名单 / 继任名单
- 各团队绩效密度
- 人均产出指标
- 近一年低绩效处理情况
- 关键人才流失数据

### D. 晋升与薪酬激励数据

- 晋升规则
- 晋升窗口和评审流程
- 近 2-4 次晋升名单与通过率
- 各职级晋升周期
- 晋升后薪酬变化
- 调薪、奖金、股权、专项激励规则
- 例外晋升 / 快速晋升案例

### E. 招聘与流失数据

- 招聘 JD
- 各岗位招聘周期
- offer 接受率
- 候选人流失原因
- 关键岗位薪酬对标
- 离职员工去向
- 离职访谈记录

### F. AI 使用与工作方式变化数据

- 内部 AI 工具使用数据
- 各团队 AI 使用率
- AI 使用场景清单
- AI 提效案例
- AI 失败案例 / 风险案例
- 代码、内容、客服、运营等场景的 AI 参与比例
- 员工对 AI 工具的反馈

### G. 项目与协作数据

- 重点项目清单
- 项目团队构成
- 项目周期
- 项目 owner
- 跨部门协作流程
- 项目复盘
- 重大延期、返工、质量事故记录

### H. 员工声音与管理者反馈

- 员工敬业度调研
- 组织氛围调研
- 管理者访谈纪要
- 员工访谈纪要
- 脉冲调研
- 晋升 / 绩效 / AI 工具 / 组织调整相关反馈
- 匿名问题池

## 3. 脱敏要求

可以脱敏，但请尽量保留结构关系：

- 员工姓名替换为 `E001 / E002 / E003`
- 管理者姓名替换为 `M001 / M002`
- 部门名称可以保留；如必须脱敏，可保留层级与业务类型，如“业务线A-销售一区”
- 薪酬可用区间、分位数或相对值，不必须给绝对金额
- 绩效可用等级，不必须给原始评分
- 离职原因、访谈内容可去掉个人身份信息

关键是保留这些关系：

- 谁在哪个团队
- 什么岗位
- 什么职级
- 向谁汇报
- 绩效如何
- 是否晋升
- 是否调薪
- 是否流失
- 是否参与关键项目
- 是否有 AI 使用/提效/风险案例

## 4. 交付格式

推荐优先使用表格：

- `.xlsx`
- `.csv`
- `.numbers` 导出 CSV
- 飞书/企业微信表格导出

访谈和制度材料可以使用：

- `.docx`
- `.md`
- `.pdf`
- 截图也可以，但最好同时给文字版

## 5. 我会如何使用这些数据

拿到数据后，会输出：

- 内部组织变化诊断
- 外部案例与内部现状对照
- 组织扁平化可行性判断
- 高人才密度识别与风险分析
- 岗位族群/序列建设建议
- 晋升机制与激励机制建议
- CEO / C-level 周报中的内部变化部分
- 需要 CEO 拍板的组织议题清单
