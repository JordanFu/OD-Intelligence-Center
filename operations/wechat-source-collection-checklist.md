# 微信公众号信息源采集清单

## 适用范围

用于采集微信公众号「AI组织进化论」及同类国内垂直公众号。目标是拓宽信息获取路径，但不降低证据质量。

## 每日执行顺序

1. **微信内搜索**
   - 搜公众号名、文章标题关键词、主题关键词。
   - 记录：标题、发布日期、作者、原文链接、摘要、所属主题。
2. **公众号主页**
   - 查看最近文章、合集、历史精选、相关阅读。
   - 若无法复制链接，记录可复查线索并进入“待补链”。
3. **原文链接保存**
   - 优先保存 `mp.weixin.qq.com` 链接。
   - 保存到日报来源索引或知识库来源摘要页。
4. **搜狗微信补检**
   - 使用 `site:weixin.sogou.com AI组织进化论` 和文章标题反查。
   - 只作为发现入口，不能替代原文。
5. **外部搜索反查**
   - 使用文章标题、核心短句、作者名、案例公司名检索转载和引用。
   - 若公开 Web 不命中，记录“公开 Web 未覆盖”，不要删除线索。
6. **转载/摘录/截图处理**
   - 截图、群聊转述、转载摘录只进线索层。
   - 标注“待原文核验”，不得进入结论层。
7. **交叉验证**
   - 对涉及公司案例、岗位机制、薪酬激励、绩效晋升的内容，继续找官方材料、招聘 JD、薪酬信号、权威媒体或制度文件。

## 入库字段

- 标题
- 公众号
- 作者
- 发布日期
- 原文链接
- 获取路径：微信内搜索 / 原文链接 / 搜狗微信 / 转载 / 截图 OCR / 用户补链
- 主题标签：岗位重构 / 职级序列 / 人才密度 / 管理者角色 / 薪酬激励 / 绩效晋升 / 组织案例 / 方法论
- 证据层级：线索 / 背景材料 / 结论候选
- 可互证来源
- 今日使用方式：不使用 / 线索池 / Context / 结论层

## 质量红线

- 不能把公众号观点写成公司事实。
- 不能把截图和二手转载当作原文。
- 不能只因为文章观点符合既有判断就进入结论层。
- 没有来源链接时，可以保留线索，但必须写明“待核验”。
