# 情报中心信息源准入规则

## 总原则

情报中心不是四专题日报的附属物，而是 OD、AI 和未来组织的长期前沿雷达。每日采集要尽可能覆盖海内外企业、咨询机构、媒体、公众号、社媒、招聘 JD、薪酬信号和报告/PDF，并通过多渠道互相校验。专题项目只吸收其中与四课题强相关的材料做深加工，不能替代信息库本身。

## 每日渠道代理矩阵

| 渠道代理 | 主要来源 | 每日任务 | 进入信息库条件 |
|---|---|---|---|
| 官方/一手材料 | 公司官网、官方博客、新闻稿、IR、SEC、产品文档、政策文件、官方白皮书 | 找新增组织、岗位、产品化工作流、AI 治理、人才机制、管理制度信号 | 有明确主体、时间、动作和原文链接 |
| 权威媒体与案例 | Reuters、FT、WSJ、The Information、Bloomberg、36氪、虎嗅、机器之心、晚点、财经媒体 | 找企业改革、组织调整、裁撤/扩招、管理层级变化和争议 | 至少说明报道事实与 OD 机制关系 |
| 咨询/学术/报告 | McKinsey、BCG、Bain、Deloitte、Mercer、Gartner、WEF、OECD、MIT、Stanford、HBR、AIHR | 找趋势、框架、数据、调研样本和方法论 | 标注样本范围、口径限制和证据层级 |
| 社媒/职场/公众号 | LinkedIn、Reddit、Hacker News、脉脉、知乎、小红书、微信公众号「AI组织进化论」及同类垂直号 | 找早期弱信号、员工体感、岗位变化、企业实践讨论 | 默认进入 Context/线索层，不能直接当结论 |
| 招聘 JD 与薪酬 | 公司招聘页、LinkedIn Jobs、Levels.fyi、Payscale、薪酬报告、猎头/招聘信息 | 找 title 合并/拆分、技能要求、薪酬溢价、职级边界、IC/Manager 变化 | 保留岗位原文、地区、薪资区间、职责和技能要求 |

主代理每日必须做四件事：

1. 去重：同一事件多来源合并，保留最强原始来源。
2. 互证：用官方、媒体、报告、社媒/JD/薪酬信号互相校验。
3. 分层：L3/L4 才能进入结论层；L1/L2 保留在 Context 或线索池。
4. 翻译：每条高价值信息必须说明它对应的 OD 机制，例如角色边界、岗位族群、职级晋升、薪酬激励、管理跨度、决策权、工作流或智能体治理。

## 微信公众号「AI组织进化论」

- **定位**：国内垂直内容源、观点源、案例线索源；重点服务 AI 组织设计、组织进化、岗位重构、人才密度、管理者角色、绩效激励、薪酬机制和组织案例追踪。
- **默认证据层级**：L1-L2。公众号文章本身不等同公司官方事实；除非文章引用了公司公告、制度原文、招聘 JD、薪酬数据或可访问的一手材料，否则不直接进入结论层。

### 多路径获取矩阵

| 路径 | 用途 | 可进入层级 | 处理规则 |
|---|---|---|---|
| 微信内搜索 | 找首发文章、历史文章、合集和同号相关文章 | Context/线索 | 优先获取原文标题、发布日期、作者、原文链接；无法导出链接时记录检索词和截图说明 |
| `mp.weixin.qq.com` 原文链接 | 保存可追溯来源 | Context/结论候选 | 有原文链接且内容含案例、制度、数据或明确观点时可进入 Context；需互证后进结论 |
| 搜狗微信搜索 | 补充微信生态外可检索入口 | Context/线索 | 用于发现标题和摘要；必须回到原文或其他来源核验 |
| 微信公众号转载/二次分发 | 找被转载的文章和摘要 | 线索 | 只记录转载来源、标题和疑似原文信息，不直接当事实 |
| 外部搜索引擎 | 查找文章标题、作者、摘录、引用痕迹 | 线索 | 普通 Web 搜索未命中时，不视为来源不存在；只说明公开 Web 未覆盖 |
| 用户人工补链 | 用最低摩擦方式补原文 | Context/结论候选 | 用户转发文章链接、复制标题/摘要或导出截图后，按原文核验流程入库 |
| 截图/OCR/人工摘录 | 处理无法导出的微信内容 | 线索 | 必须标注“截图/OCR线索，待原文核验”；不得进入结论层 |

### 每日采集动作

1. 先查微信内搜索和公众号主页：记录当天/近 7 天新文标题、日期、作者、原文链接。
2. 再查搜狗微信和外部搜索：用标题反查是否有可访问网页、转载、引用或摘要。
3. 对每篇候选文章打标签：`岗位重构`、`职级/序列`、`人才密度`、`管理者角色`、`薪酬激励`、`绩效晋升`、`组织案例`、`方法论`。
4. 若文章引用公司案例，必须继续找公司官方、招聘 JD、薪酬或权威媒体材料做交叉验证。
5. 当天无法获取原文时，仍保留到线索池，不删除；下一轮继续补链。
- **可进入 Context 层的条件**：
  - 能取得可访问原文链接；
  - 文章包含明确主体、时间、事件、案例、制度片段或可追踪的观点；
  - 已在日报中标注为“微信公众号「AI组织进化论」观点/线索”，不写成官方事实。
- **可进入结论层的条件**：
  - 与官方材料、权威媒体、招聘 JD、薪酬信号或公司制度文件形成互证；
  - 主代理能说明它支持哪个判断、证据强度为何、还有哪些反例。
- **只能进入线索层的情况**：
  - 只有截图、转载、群聊摘录、二手转述；
  - 无原文链接或无法确认发布日期；
  - 只有观点判断，没有案例事实或可追踪材料。

- **页面呈现写法**：统一写作 `微信公众号「AI组织进化论」`；不得把公众号观点包装成一手材料。
