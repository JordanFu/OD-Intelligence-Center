# OD 微信公众号情报通道

## 定位

这是 OD Intelligence Center 的独立公众号信源暂存区。它负责发现、抓取、去重和初筛，不直接替代综合日报、专题研究或知识库结论。

公众号内容默认属于 L1-L2 线索或事实观察。只有经过官方材料、权威媒体、招聘岗位说明、薪酬数据或制度文件互证后，才能作为 L3 结论候选。

## 课题范围

- AI 组织设计与组织变革
- AI 治理、智能体权限与责任边界
- 组织效能、人效与管理跨度
- 岗位族群、职级、晋升与人才密度
- 绩效、薪酬与激励机制
- HR Tech 与 AI 原生工作流
- 管理者角色、人机协作与组织能力建设

## 目录约定

```text
research/wechat-od-intel/
|-- README.md
|-- source-registry.md
|-- queue.md
|-- intake/
|-- daily/
`-- archive/
```

- `source-registry.md`：公众号种子池、优先级和升降级记录。
- `queue.md`：尚未完成一手互证的候选文章。
- `intake/urls.txt`：人工或已授权历史导出提供的公开文章 URL 收件箱；仅接收 `mp.weixin.qq.com` 公开链接，一行一个。自动任务处理成功后会在日报中记录，不保存任何登录凭证。
- `intake/README.md`：URL 收件箱和历史导入的使用说明。
- `daily/YYYY-MM-DD.md`：当日扫描范围、候选条目和“无新增”说明。
- `archive/YYYY-MM-DD/`：公开文章正文、索引和抓取错误；不存放 cookies、auth-key、token、pass_ticket、uin 或微信登录凭证。

## 每日门禁

每条候选至少记录：标题、公众号、作者、发布日期、原文链接、获取路径、主题标签、事实摘要、OD 机制、证据层级、互证状态和建议使用方式。

公众号观点不能写成公司事实；截图、转载和无原文链接的内容只进入待核验队列。没有高价值新增时明确写“今日无新增”，不为了数量填充。

## 安全边界

- 自动任务不得控制微信界面、扫码、登录、改代理或安装证书。
- 已知公开文章 URL 可通过 `wechat-mp-batch-exporter` 下载；其默认服务会把公开 URL 发给 `down.mptext.top`。
- 公众号历史列表的完整同步需要用户亲自完成公众号后台扫码授权，自动任务不能代替。
- 原文只用于合法的私人研究和引用核验，不公开转载全文。

## 稳定采集入口

优先级最高的发现入口是 `intake/urls.txt`：把公开文章 URL（每行一个）放入该文件，日常任务会先去重、抓取和筛选，再做公开 Web 补充发现。

如果要主动同步核心账号历史，请由拥有公众号后台权限的用户完成扫码授权并导出历史 URL/JSON；不要把 cookies、auth-key、token、pass_ticket、key、uin 或凭证 JSON 放入本目录。历史导出文件应放在本地受控位置，由任务按需读取并生成去重后的公开 URL 列表。
