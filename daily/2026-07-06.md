3. **HR / 审计 / 学术线索共同指向“治理劳动外显”**：Workday 的 agent system of record、Deloitte AI assurance、HR GenAI 研究和 invisible-work 研究都说明，AI 落地后新增的不是少量 prompt 技巧，而是一整套验证、解释、审计、权限、例外处理和员工信任工作。

## 落地启发

- 评估 coding agent 时，不要只看个人任务时长；要同时看 review 负担、返工率、生产事故、知识沉淀、junior 成长和跨系统授权。
- 设立 FDE / AI deployment team 时，必须定义它和销售、咨询、解决方案架构、客户成功、产品工程、SI 伙伴的边界，以及客户自给能力如何退出。
- HR / OD 要把 agent 纳入“组织对象”管理：身份、owner、权限、训练数据、输出验证、异常升级、停用机制和审计日志都需要制度化。
- 对 junior roles 的 AI 改造不能只做 headcount 优化；如果低阶任务被自动化，企业需要重新设计 apprenticeship、case exposure、反馈循环和判断力训练。
